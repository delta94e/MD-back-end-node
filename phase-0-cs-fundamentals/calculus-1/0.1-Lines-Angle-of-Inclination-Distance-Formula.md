## 1. Slope — Độ Dốc Của Đường Thẳng

### 1.1 Đường Thẳng Là Gì? (Giải Thích Cho Beginner)

> Trước khi nói về slope, ta cần hiểu rõ **đường thẳng (line)** là gì.

```
╔══════════════════════════════════════════════════════════════════╗
║  ĐƯỜNG THẲNG (LINE) có 4 tính chất:                              ║
╠══════════════════════════════════════════════════════════════════╣
║                                                                  ║
║  1. THẲNG — không cong, không gấp khúc                           ║
║     ✅ Thẳng: ──────────────                                    ║
║     ❌ Cong: ~~~~~~~~~                                           ║
║     ❌ Gấp: ──╲──╱──                                            ║
║                                                                  ║
║  2. VÔ TẬN — kéo dài mãi mãi 2 phía, không có đầu/cuối        ║
║     ←──────────────────────────→  (mũi tên = vô tận)            ║
║                                                                  ║
║  3. CẦN 2 ĐIỂM — tối thiểu 2 điểm để xác định 1 line duy nhất ║
║     1 điểm → vô số line đi qua (quay tròn quanh điểm)          ║
║     2 điểm → CHỈ CÓ 1 line duy nhất đi qua cả hai             ║
║                                                                  ║
║  4. CÓ SLOPE — mô tả "dốc" bao nhiêu (đây là phần quan trọng!) ║
║                                                                  ║
╚══════════════════════════════════════════════════════════════════╝
```

### 1.2 Ôn Lại — Hệ Tọa Độ (Coordinate Plane)

> Nếu bạn chưa rõ về hệ tọa độ, đọc phần này. Nếu đã biết → skip sang 1.3.

```
       y (trục đứng)
       │
   4   │
   3   │         • (3, 2) ← "x = 3, y = 2"
   2   │         │
   1   │         │
───────┼─────────┼──── x (trục ngang)
  -1   │  0    1   2   3
  -2   │
       │

MỌI ĐIỂM trên mặt phẳng đều có 2 tọa độ: (x, y)
  x = bao xa sang PHẢI (dương) hoặc TRÁI (âm)
  y = bao xa lên TRÊN (dương) hoặc XUỐNG (âm)

VÍ DỤ CỤ THỂ:
  • (3, 2)  → sang phải 3, lên trên 2
  • (-1, 4) → sang trái 1, lên trên 4
  • (2, -3) → sang phải 2, xuống dưới 3
  • (0, 0)  → gốc tọa độ (origin)

⚠️ THỨ TỰ QUAN TRỌNG:
  (3, 2) ≠ (2, 3)
  Luôn là (x trước, y sau) → nhớ: "x trước y" = "trái qua phải trước"
```

### 1.3 Slope Là Gì? — Giải Thích Bằng Đời Thực

> **Slope** = "độ dốc" — mô tả đường thẳng NGHIÊNG bao nhiêu.

```
TƯỞNG TƯỢNG bạn đang leo DỐC:

    DỐC NHẸ (slope nhỏ):        DỐC GẮT (slope lớn):

         ╱                              ╱
        ╱                              ╱
       ╱  nhẹ nhàng, đi thoải mái    ╱  rất mệt, gần như leo!
      ╱                              ╱
     ╱                              ╱
    ╱                              ╱

    slope ≈ 0.1                     slope ≈ 5

BẰNG PHẲNG (slope = 0):         XUỐNG DỐC (slope âm):
    ────────────────                ╲
    không lên không xuống            ╲  đang đi xuống
                                      ╲
    slope = 0                     slope = -2

TƯỜNG (slope undefined):
    │    thẳng đứng — không đi được!
    │
    │
    slope = undefined (vô nghĩa — chia cho 0)
```

#### Slope = "Lên Bao Nhiêu Khi Đi Ngang 1 Bước"

```
CÁCH HIỂU ĐƠN GIẢN NHẤT:

  slope = 2 → mỗi bước sang PHẢI, lên 2 bậc     ╱╱ (dốc)
  slope = 1 → mỗi bước sang phải, lên 1 bậc      ╱  (vừa)
  slope = 1/2 → mỗi 2 bước sang phải, lên 1 bậc  ╱  (thoải)
  slope = 0 → đi mãi nhưng không lên xuống        ── (phẳng)
  slope = -1 → mỗi bước sang phải, XUỐNG 1 bậc    ╲  (xuống)
  slope = -3 → mỗi bước sang phải, XUỐNG 3 bậc    ╲╲ (lao xuống)
```

║                  │  ╱          │                   │ m = 0.5      ║

GHI NHỚ NHANH:
  m lớn → line DỐC hơn
  m nhỏ (gần 0) → line THOẢI hơn
  m dương → đi LÊN ╱      m âm → đi XUỐNG ╲
```

### 1.5 Rise Over Run — Hiểu Công Thức Slope

> **"Rise over Run"** — Đây là câu thần chú khi nhớ slope.

```
Rise = ĐI LÊN bao nhiêu đơn vị (theo trục y — đứng)
Run  = ĐI NGANG bao nhiêu đơn vị (theo trục x — ngang)

  slope = Rise / Run

VÍ DỤ HIỂU TRỰC QUAN:

  Bạn đang ở điểm A, muốn đi đến điểm B trên đường thẳng.

  Cách đi: NGANG TRƯỚC, rồi LÊN SAU (hoặc ngược lại).

         B (6, 5)
         │
         │  Rise = 5 - 1 = 4  (lên 4 bậc)
         │
  A (2, 1)────────┘
     Run = 6 - 2 = 4  (sang phải 4 bước)

  slope = Rise / Run = 4 / 4 = 1

  Nghĩa: Mỗi bước sang phải → lên 1 bậc. Line nghiêng 45°.
```

### 1.6 Xây Dựng Công Thức Slope — Từng Bước

> Tại sao dùng chữ (x₁, y₁) thay vì số cụ thể? Vì muốn công thức áp dụng cho **MỌI** cặp điểm.

#### Bước 1: Đặt Tên Cho 2 Điểm

```
Cho 2 ĐIỂM BẤT KỲ trên đường thẳng.

Vấn đề: Cả 2 điểm đều viết (x, y) → KHÔNG PHÂN BIỆT được!

GIẢI PHÁP: Thêm SỐ NHỎ DƯỚI (subscript):
  Điểm thứ nhất: (x₁, y₁)    đọc là "x sub 1, y sub 1"
  Điểm thứ hai:  (x₂, y₂)    đọc là "x sub 2, y sub 2"

⚠️ ĐỌC ĐÚNG:
  x₁ = "x sub 1" = tọa độ x của điểm THỨ NHẤT
  x₁ ≠ x¹ (x mũ 1 — đó là lũy thừa, hoàn toàn khác!)

  Số nhỏ DƯỚI = subscript = đánh dấu thuộc điểm nào
  Số nhỏ TRÊN = superscript = lũy thừa
```

#### Bước 2: Tính Rise (Khoảng Cách Đứng)

```
Rise = hiệu tọa độ y = y₂ - y₁

VÍ DỤ: Nếu y₁ = 3 và y₂ = 10
  Rise = 10 - 3 = 7
  → Đi LÊN 7 đơn vị

VÍ DỤ: Nếu y₁ = 8 và y₂ = 2
  Rise = 2 - 8 = -6
  → Đi XUỐNG 6 đơn vị (âm = xuống)
```

#### Bước 3: Tính Run (Khoảng Cách Ngang)

```
Run = hiệu tọa độ x = x₂ - x₁

VÍ DỤ: Nếu x₁ = 1 và x₂ = 5
  Run = 5 - 1 = 4
  → Đi SANG PHẢI 4 đơn vị
```

#### Bước 4: Chia Rise Cho Run

```
            Rise       y₂ - y₁
  slope = ────── = ─────────────
            Run       x₂ - x₁


  ┌─────────────────────────────────────────────────────┐
  │                                                     │
  │                  y₂ - y₁                            │
  │       m  =   ─────────────                          │
  │                  x₂ - x₁                            │
  │                                                     │
  │   m = slope, (x₁,y₁) = điểm 1, (x₂,y₂) = điểm 2  │
  │                                                     │
  └─────────────────────────────────────────────────────┘

  ĐỌC: "slope = y2 trừ y1, chia cho x2 trừ x1"
  NHỚ: "Rise over Run" → Y trước (đứng trên), X sau (nằm dưới)
```

### 1.7 Ví Dụ 1 — Slope Dương (Line Đi Lên)

```
Cho 2 điểm: (-2, -3) và (8, 2)

STEP 1: Gán labels (chọn điểm nào làm "thứ nhất" đều được)
  (x₁, y₁) = (-2, -3)
  (x₂, y₂) = (8, 2)

  ⚠️ QUY TẮC VÀNG: x và y phải CÙNG điểm!
    ✅ x₁ = -2, y₁ = -3   (cả 2 từ điểm (-2, -3))
    ❌ x₁ = -2, y₁ = 2    (lẫn lộn giữa 2 điểm!)

STEP 2: Thay vào công thức
  m = (y₂ - y₁) / (x₂ - x₁)
  m = (2 - (-3)) / (8 - (-2))

STEP 3: Tính — CẨN THẬN VỚI DẤU ÂM!
  Tử: 2 - (-3) = 2 + 3 = 5     ← trừ số âm = CỘNG!
  Mẫu: 8 - (-2) = 8 + 2 = 10   ← trừ số âm = CỘNG!

  m = 5/10 = 1/2

STEP 4: Hiểu kết quả
  m = 1/2 → slope DƯƠNG → line đi LÊN ╱
  Cụ thể: Mỗi 2 bước sang phải → lên 1 bậc (dốc thoải)

        y
     2  │          ╱• (8, 2)
     1  │        ╱
     0  │──────╱──────── x
    -1  │    ╱
    -2  │  ╱
    -3  │• (-2, -3)
        │╱

KIỂM TRA: Nhìn hình, line đi TỪ THẤP LÊN CAO → m dương ✅

THỬ NGƯỢC: Nếu gán (x₁,y₁) = (8,2) và (x₂,y₂) = (-2,-3):
  m = (-3 - 2) / (-2 - 8) = -5 / -10 = 1/2 ✅ (giống hệt!)
```

### 1.8 Ví Dụ 2 — Slope Âm (Line Đi Xuống)

```
Cho 2 điểm: (1, 5) và (4, -1)

STEP 1: Gán labels
  (x₁, y₁) = (1, 5)
  (x₂, y₂) = (4, -1)

STEP 2: Thay vào
  m = (y₂ - y₁) / (x₂ - x₁)
  m = (-1 - 5) / (4 - 1)

STEP 3: Tính
  Tử: -1 - 5 = -6
  Mẫu: 4 - 1 = 3

  m = -6/3 = -2

STEP 4: Hiểu kết quả
  m = -2 → slope ÂM → line đi XUỐNG ╲
  Cụ thể: Mỗi 1 bước sang phải → XUỐNG 2 bậc (dốc gắt)

        y
     5  │• (1, 5)
     4  │ ╲
     3  │  ╲
     2  │   ╲
     1  │    ╲
     0  │─────╲──────── x
    -1  │      ╲• (4, -1)

KIỂM TRA: Nhìn hình, line đi TỪ CAO XUỐNG THẤP → m âm ✅
```

### 1.9 Ví Dụ 3 — Slope = 0 (Line Nằm Ngang)

```
Cho 2 điểm: (2, 4) và (7, 4)

  m = (4 - 4) / (7 - 2)
  m = 0 / 5
  m = 0

  y₁ = y₂ = 4 → cùng độ cao → NGANG!

        y
     4  │• ─────────── • (7, 4)
     3  │   (2, 4)
     0  │───────────────── x

  Nhìn hình: line PHẲNG, không lên không xuống → m = 0 ✅
```

### 1.10 Ví Dụ 4 — Slope Undefined (Line Thẳng Đứng)

```
Cho 2 điểm: (3, 1) và (3, 8)

  m = (8 - 1) / (3 - 3)
  m = 7 / 0
  m = UNDEFINED! ← chia cho 0 → không tồn tại!

  x₁ = x₂ = 3 → cùng vị trí ngang → ĐỨNG!

        y
     8  │  • (3, 8)
     7  │  │
     6  │  │
     5  │  │
     4  │  │  ← đường thẳng ĐỨNG
     3  │  │
     2  │  │
     1  │  • (3, 1)
     0  │──┼────────── x
           3

  Phương trình: x = 3 (mọi điểm trên line đều có x = 3)
  KHÔNG CÓ slope → gọi là UNDEFINED.
```

### 1.12 Bài Tập Thực Hành

```
Tính slope cho các cặp điểm sau:

1) (0, 0) và (4, 8)       → m = ?
2) (3, 7) và (3, -2)      → m = ?  (cẩn thận!)
3) (-5, 2) và (1, 2)      → m = ?  (cẩn thận!)
4) (-3, -4) và (2, 6)     → m = ?
5) (10, 1) và (2, 5)      → m = ?

═══ ĐÁP ÁN ═══

1) m = (8-0)/(4-0) = 8/4 = 2          (dương → đi lên ╱)
2) m = (-2-7)/(3-3) = -9/0 = UNDEFINED (đứng → x = 3 │)
3) m = (2-2)/(1-(-5)) = 0/6 = 0       (ngang → y = 2 ──)
4) m = (6-(-4))/(2-(-3)) = 10/5 = 2   (dương → đi lên ╱)
5) m = (5-1)/(2-10) = 4/(-8) = -1/2   (âm → đi xuống ╲)
```

## 2. Point-Slope Form — Phương Trình Điểm-Độ Dốc

### 2.1 Tại Sao Cần "Phương Trình" Cho Đường Thẳng?

> Trước khi học Point-Slope, hãy hiểu TẠI SAO ta cần phương trình.

```
2 ĐIỂM cho ta 1 đường thẳng CỤ THỂ trên giấy.
Nhưng nếu muốn:
  • Tìm y khi biết x? (ví dụ: x = 100 thì y = bao nhiêu?)
  • Vẽ trên máy tính?
  • Dùng trong tính toán khác?

→ Ta cần PHƯƠNG TRÌNH — một "công thức" mà:
   plug X vào → ra Y tương ứng.

VÍ DỤ:
  Phương trình: y = 2x + 1

  x = 0 → y = 2(0) + 1 = 1     → điểm (0, 1)
  x = 3 → y = 2(3) + 1 = 7     → điểm (3, 7)
  x = -2 → y = 2(-2) + 1 = -3  → điểm (-2, -3)

  → VÔ SỐ điểm, tất cả nằm trên CÙNG 1 đường thẳng!
```

### 2.2 Ý Tưởng — "Fix" 1 Điểm, "Thả" Điểm Kia

> Đây là bước quan trọng nhất để hiểu Point-Slope.

```
Nhớ lại SLOPE FORMULA:

         y₂ - y₁
  m = ─────────────
         x₂ - x₁

Công thức này cần 2 điểm CỐ ĐỊNH: (x₁, y₁) và (x₂, y₂).
→ Nó chỉ cho ta 1 con số (slope), KHÔNG cho phương trình.

Ý TƯỞNG THIÊN TÀI:
  Giữ 1 điểm CỐ ĐỊNH (known) → gọi là (x₁, y₁)
  Để điểm kia TỰ DO (floating) → gọi là (x, y)

  (x₁, y₁) = điểm CỤ THỂ bạn BIẾT — ví dụ (3, 5)
  (x, y)   = điểm BẤT KỲ trên line — viết BẰNG CHỮ, không số

TRƯỚC:                          SAU:
  (x₁, y₁) và (x₂, y₂)          (x₁, y₁) và (x, y)
  ↓                                ↓
  Cả 2 cố định                    1 cố định + 1 tự do
  ↓                                ↓
  Ra 1 con số (slope)              Ra 1 PHƯƠNG TRÌNH (line)!
```

### 2.3 Biến Đổi Từng Bước — Từ Slope → Point-Slope

> Hãy theo dõi TỪNG BƯỚC biến đổi. Mỗi bước chỉ làm 1 việc.

```
═══ BƯỚC 1: Bắt đầu với slope formula ═══

         y₂ - y₁
  m = ─────────────        ← công thức slope gốc
         x₂ - x₁

═══ BƯỚC 2: Thay (x₂, y₂) bằng (x, y) ═══

  Bỏ subscript "2" → (x₂, y₂) trở thành (x, y):

         y - y₁
  m = ─────────────        ← bây giờ x, y là BIẾN (variable)
         x - x₁

  Tại sao? Vì (x, y) "float" — nó là BẤT KỲ điểm nào trên line.
  Khi bạn plug 1 x vào → ra y tương ứng = phương trình!

═══ BƯỚC 3: Nhân 2 vế với (x - x₁) ═══

  Mục đích: bỏ mẫu số, đưa về dạng dễ nhìn.

  m × (x - x₁) = y - y₁

  Giải thích algebra:
                 y - y₁
    m = ─────────────       ← bắt đầu
                 x - x₁

    m × (x - x₁) = y - y₁   ← nhân (x - x₁) cả 2 vế
                                 vế phải: (x-x₁) ở trên & dưới triệt tiêu
                                 chỉ còn y - y₁

═══ BƯỚC 4: Đổi vế (viết gọn) ═══

  Thay vì:  m(x - x₁) = y - y₁  (slope bên trái)
  Viết lại: y - y₁ = m(x - x₁)  (y bên trái — quen thuộc hơn)

  ┌─────────────────────────────────────────────────────┐
  │                                                     │
  │        y - y₁ = m(x - x₁)                          │
  │                                                     │
  │        ↑   ↑    ↑  ↑   ↑                            │
  │        │   │    │  │   │                             │
  │        y  y₁    m  x  x₁                            │
  │        │   │    │  │   │                             │
  │      biến │  slope │  từ điểm                       │
  │        │  từ điểm  biến  cố định                    │
  │        │  cố định                                   │
  │                                                     │
  │   Đây là POINT-SLOPE FORM                           │
  │                                                     │
  └─────────────────────────────────────────────────────┘
```

### 2.4 Cách Dùng — Template

```
Để viết phương trình đường thẳng, bạn cần:
  ✅ 1 POINT (điểm): (x₁, y₁)
  ✅ 1 SLOPE (độ dốc): m

Rồi điền vào template:

  y - [  y₁  ] = [  m  ] × (x - [  x₁  ])
       ↑              ↑              ↑
    y của điểm      slope         x của điểm

VÍ DỤ NHANH:
  Point (3, 5), slope m = 2:
  y - 5 = 2(x - 3)         ← XONG! Đó là point-slope form.

TẠI SAO GỌI LÀ "Point-Slope"?
  → Cần 1 POINT + 1 SLOPE → đặt tên luôn theo 2 cái cần.
  → Mathematicians rất thực tế khi đặt tên 😄
```

### 2.5 Ví Dụ 1 — Từ 2 Điểm → Phương Trình (Đầy Đủ Các Bước)

```
BÀI: Tìm phương trình đường thẳng qua (-2, -3) và (8, 2).

╔═══════════════════════════════════════════════════════════════╗
║ TRƯỚC KHI BẮT ĐẦU: 2 điều bạn CẦN cho point-slope          ║
║   ✅ Point? CÓ — (-2, -3) hoặc (8, 2) — chọn 1             ║
║   ✅ Slope? CHƯA — phải tính trước!                          ║
╚═══════════════════════════════════════════════════════════════╝

STEP 1: Tính slope
  m = (2 - (-3)) / (8 - (-2))
  m = 5 / 10
  m = 1/2                      ← đã có slope!

STEP 2: Chọn 1 điểm
  Chọn (-2, -3) làm (x₁, y₁).
  (chọn điểm nào cũng được — kết quả luôn giống nhau)

STEP 3: Điền vào Point-Slope
  y - y₁ = m(x - x₁)
  y - (-3) = (1/2)(x - (-2))
       ↑            ↑
    thay y₁=-3   thay x₁=-2

STEP 4: Đơn giản hóa dấu
  y - (-3) = y + 3         ← trừ số âm = cộng
  x - (-2) = x + 2         ← trừ số âm = cộng

  ┌─────────────────────────────────┐
  │  y + 3 = (1/2)(x + 2)          │  ← POINT-SLOPE FORM ✅
  └─────────────────────────────────┘

STEP 5: Chuyển về Slope-Intercept (nếu cần)
  y + 3 = (1/2)(x + 2)

  Distribute (phân phối):
    y + 3 = (1/2)(x) + (1/2)(2)
    y + 3 = (1/2)x + 1

  Trừ 3 cả 2 vế:
    y = (1/2)x + 1 - 3
    y = (1/2)x - 2

  ┌─────────────────────────────────┐
  │  y = (1/2)x - 2                 │  ← SLOPE-INTERCEPT FORM ✅
  └─────────────────────────────────┘
```

### 2.6 Ví Dụ 2 — Dùng Điểm Khác (Chứng Minh Kết Quả Giống)

```
BÀI: Cùng bài trên, nhưng chọn (8, 2) làm point.

  m = 1/2 (đã tính ở trên)
  Point: (x₁, y₁) = (8, 2)

  y - 2 = (1/2)(x - 8)          ← point-slope form

  Distribute:
    y - 2 = (1/2)x - 4

  Cộng 2 cả 2 vế:
    y = (1/2)x - 4 + 2
    y = (1/2)x - 2               ← GIỐNG HỆT! ✅

BÀI HỌC: Điểm nào cũng cho ra CÙNG đường thẳng.
  Point-slope form nhìn KHÁC nhau:
    y + 3 = (1/2)(x + 2)    ← dùng (-2, -3)
    y - 2 = (1/2)(x - 8)    ← dùng (8, 2)
  Nhưng slope-intercept form RA GIỐNG:
    y = (1/2)x - 2           ← cả 2 đều ra đây
```

### 2.7 Ví Dụ 3 — Khi Cho Sẵn Slope + 1 Điểm

```
BÀI: Line có slope m = -3 và đi qua điểm (2, 7).
     Tìm phương trình.

  Đã có sẵn:
    ✅ slope m = -3
    ✅ point (2, 7)
  → Không cần tính slope — plug thẳng vào!

  y - y₁ = m(x - x₁)
  y - 7 = -3(x - 2)             ← POINT-SLOPE FORM ✅

  Chuyển slope-intercept:
    y - 7 = -3x + 6              (distribute: -3 × -2 = +6)
    y = -3x + 6 + 7
    y = -3x + 13                 ← SLOPE-INTERCEPT FORM ✅

KIỂM TRA: Plug (2, 7) vào y = -3x + 13:
  y = -3(2) + 13 = -6 + 13 = 7 ✅ (đúng!)
```

### 2.8 Distribute — Ôn Lại Cho Beginner

> Nhiều bạn quên cách "distribute" (phân phối). Đây là ôn nhanh.

```
DISTRIBUTE = nhân SỐ NGOÀI vào TỪNG phần TRONG ngoặc.

  a(b + c) = ab + ac
  a(b - c) = ab - ac

VÍ DỤ VỚI SỐ:
  3(x + 5) = 3·x + 3·5 = 3x + 15
  2(x - 4) = 2·x + 2·(-4) = 2x - 8
  -5(x + 3) = -5·x + (-5)·3 = -5x - 15

VÍ DỤ VỚI PHÂN SỐ:
  (1/2)(x + 2) = (1/2)·x + (1/2)·2 = (1/2)x + 1
  (2/3)(x - 6) = (2/3)·x + (2/3)·(-6) = (2/3)x - 4
  (-3/4)(x + 8) = (-3/4)·x + (-3/4)·8 = (-3/4)x - 6

⚠️ CẨN THẬN DẤU ÂM:
  -2(x - 5) = -2·x + (-2)·(-5) = -2x + 10
                                          ↑
                               âm × âm = DƯƠNG!
```

### 2.9 Hai Dạng — So Sánh Point-Slope vs Slope-Intercept

```
╔══════════════════════════════════════════════════════════════════╗
║                  │ Point-Slope         │ Slope-Intercept          ║
╠══════════════════════════════════════════════════════════════════╣
║ Dạng tổng quát  │ y - y₁ = m(x - x₁) │ y = mx + b               ║
║                  │                     │                          ║
║ Cần gì?          │ 1 point + slope     │ slope + y-intercept      ║
║                  │                     │                          ║
║ Cho thấy gì?    │ 1 điểm trên line   │ Nơi line CẮT trục Y     ║
║                  │ + slope             │ + slope                  ║
║                  │                     │                          ║
║ Khi nào dùng?   │ Khi BIẾT 1 điểm    │ Khi muốn VẼ ĐỒ THỊ     ║
║                  │ + slope             │ hoặc đọc slope/b nhanh  ║
║                  │                     │                          ║
║ Từ 2 điểm?      │ Tính slope → dùng  │ Tính slope → point-slope ║
║                  │ 1 điểm             │ → chuyển sang form này   ║
╚══════════════════════════════════════════════════════════════════╝

WORKFLOW PHỔ BIẾN:
  Bài cho 2 điểm
    → Tính slope
    → Viết point-slope (dễ nhất)
    → Distribute + đơn giản → slope-intercept (dễ vẽ nhất)
```

### 2.10 Sai Lầm Phổ Biến

```
╔══════════════════════════════════════════════════════════════════╗
║ #  │ SAI LẦM                          │ SỬA                     ║
╠══════════════════════════════════════════════════════════════════╣
║ 1  │ Đổi dấu khi thay số âm:          │ y - (-3) = y + 3       ║
║    │ y - (-3) = y - 3 ❌              │ x - (-2) = x + 2       ║
║    │                                   │ Trừ âm = CỘNG!          ║
╠══════════════════════════════════════════════════════════════════╣
║ 2  │ Quên distribute đều:              │ (1/2)(x + 2)           ║
║    │ (1/2)(x + 2) = (1/2)x + 2 ❌    │ = (1/2)x + (1/2)(2)    ║
║    │ (chỉ nhân x, quên nhân 2)        │ = (1/2)x + 1 ✅        ║
╠══════════════════════════════════════════════════════════════════╣
║ 3  │ Nhầm dấu trong template:          │ Template là y - y₁     ║
║    │ y + y₁ = m(x + x₁) ❌           │ và x - x₁ (cả 2 TRỪ)  ║
║    │                                   │ y - y₁ = m(x - x₁) ✅ ║
╠══════════════════════════════════════════════════════════════════╣
║ 4  │ Distribute sai dấu:               │ -3(x - 2)              ║
║    │ -3(x - 2) = -3x - 6 ❌          │ = -3·x + (-3)·(-2)     ║
║    │                                   │ = -3x + 6 ✅            ║
║    │                                   │ (âm × âm = DƯƠNG)      ║
╠══════════════════════════════════════════════════════════════════╣
║ 5  │ Quên 1 bước khi giải y:           │ y + 3 = (1/2)x + 1    ║
║    │ Dừng ở y + 3 = ... ❌            │ y = (1/2)x + 1 - 3     ║
║    │ (chưa isolate y)                  │ y = (1/2)x - 2 ✅      ║
╚══════════════════════════════════════════════════════════════════╝
```

### 2.11 Bài Tập Thực Hành

```
Viết phương trình dạng SLOPE-INTERCEPT (y = mx + b):

1) m = 4, point (1, 3)
2) m = -2, point (0, 5)
3) Points: (1, 1) và (3, 7)
4) Points: (4, 0) và (0, -8)
5) m = 1/3, point (-6, 2)

═══ ĐÁP ÁN ═══

1) y - 3 = 4(x - 1) → y = 4x - 4 + 3 → y = 4x - 1
2) y - 5 = -2(x - 0) → y = -2x + 5
   (hoặc thấy ngay: b = 5, m = -2 → y = -2x + 5)
3) m = (7-1)/(3-1) = 6/2 = 3
   y - 1 = 3(x - 1) → y = 3x - 3 + 1 → y = 3x - 2
4) m = (-8-0)/(0-4) = -8/-4 = 2
   y - 0 = 2(x - 4) → y = 2x - 8
5) y - 2 = (1/3)(x - (-6))
   y - 2 = (1/3)(x + 6)
   y - 2 = (1/3)x + 2
   y = (1/3)x + 4
```

## 3. Slope-Intercept Form — Đồ Thị Đường Thẳng

### 3.1 Dạng Tổng Quát

```
  ┌─────────────────────────────────┐
  │  y = mx + b                      │  ← SLOPE-INTERCEPT FORM
  └─────────────────────────────────┘

  m = slope (độ dốc)
  b = y-intercept (giao điểm với trục Y)

TẠI SAO GỌI LÀ "Slope-Intercept"?
  → Vì nhìn vào là THẤY NGAY slope (m) và y-intercept (b).
  → Rất dễ vẽ đồ thị từ form này.
```

### 3.2 Cách Vẽ Đồ Thị Từ Slope-Intercept

```
VÍ DỤ: y = (1/2)x - 2

STEP 1: Plot y-intercept
  b = -2 → chấm điểm (0, -2) trên trục Y
  ("-2" = đi XUỐNG 2 đơn vị từ gốc tọa độ)

STEP 2: Dùng slope để tìm điểm tiếp theo
  m = 1/2 = rise/run = 1 UP / 2 RIGHT

  Từ (0, -2):
    → ĐI LÊN 1 (rise = +1)
    → ĐI SANG PHẢI 2 (run = +2)
    → Đến điểm (2, -1)

       y
       │        ╱
       │      (2,-1)
       │      ╱
   ────(0,-2)────── x
       │╱
       │

STEP 3: Nối 2 điểm → đường thẳng → kéo dài vô tận 2 phía

QUY TẮC VỀ DẤU CỦA SLOPE:
  • m > 0 (dương): line đi LÊN từ trái sang phải  ╱
  • m < 0 (âm):    line đi XUỐNG từ trái sang phải ╲
  • m = 0:         line NẰM NGANG ──
  • m undefined:   line THẲNG ĐỨNG │

⚠️ LUÔN ĐI SANG PHẢI cho run!
  Dấu +/- của slope chỉ quyết định LÊN hay XUỐNG.
  m = -1/2 → đi XUỐNG 1, sang PHẢI 2
```

## 5. Standard Form → Slope-Intercept

### 5.1 Standard Form

```
  ┌─────────────────────────────────┐
  │  Ax + By = C                     │  ← STANDARD FORM
  └─────────────────────────────────┘

  A, B, C là hằng số.
  Muốn vẽ đồ thị → chuyển về slope-intercept (giải cho y).
```

### 5.2 Ví Dụ Chuyển Đổi

```
Cho: 4x + 2y = 3

CÁCH 1 (truyền thống):
  2y = -4x + 3         (trừ 4x cả 2 vế)
  y = -2x + 3/2        (chia 2 cả 2 vế)

CÁCH 2 (nhanh hơn):
  2y = -4x + 3         (chuyển 4x sang)

  Hoặc: trừ 2y cả 2 vế:
  4x - 3 = -2y
  y = (-4x + 3) / (-2)
  y = 2x - 3/2         ← SAI DẤU!

  → CẨN THẬN: chia cho số ÂM → đổi dấu TẤT CẢ!
  4x / (-2) = -2x ✅
  3 / (-2) = -3/2   nhưng đang là (-3)/(-2) = +3/2 ✅

  y = -2x + 3/2 ✅

KẾT QUẢ: y = -2x + 3/2
  m = -2 (slope)
  b = 3/2 (y-intercept)
```

### 5.3 Cover-Up Method — Vẽ Nhanh Từ Standard Form

```
Từ standard form: 4x + 2y = 3

TÌM X-INTERCEPT (y = 0):
  Cover up y → 4x = 3 → x = 3/4
  → x-intercept: (3/4, 0)

TÌM Y-INTERCEPT (x = 0):
  Cover up x → 2y = 3 → y = 3/2
  → y-intercept: (0, 3/2)

→ Plot 2 intercepts → nối lại = đường thẳng.
   Đôi khi DỄ HƠN slope-intercept khi có phân số lẻ!
```

## 6. Parallel & Perpendicular Lines

### 6.1 Parallel Lines — Đường Song Song

```
  ┌─────────────────────────────────────────┐
  │  Parallel ⟺ CÙNG SLOPE                  │
  │  m₁ = m₂                                │
  └─────────────────────────────────────────┘

VÌ SAO? Giống leo cầu thang:
  Mỗi bậc cầu thang có CÙNG rise/run.
  Nếu khác → các bậc sẽ GIAO NHAU ở đâu đó → không parallel.

VÍ DỤ:
  y = 2x + 1  và  y = 2x - 5  → song song (cùng m = 2)
  y = 2x + 1  và  y = 3x + 1  → KHÔNG song song (m khác nhau)
```

### 6.2 Perpendicular Lines — Đường Vuông Góc

```
  ┌───────────────────────────────────────────────┐
  │  Perpendicular ⟺ NEGATIVE RECIPROCAL slopes   │
  │  m₁ × m₂ = -1                                 │
  │  m₂ = -1/m₁                                   │
  └───────────────────────────────────────────────┘

NEGATIVE = đổi dấu
RECIPROCAL = lật phân số

VÍ DỤ:
  m₁ = 2/3  →  m₂ = -3/2  (đổi dấu + lật)
  m₁ = -4   →  m₂ = 1/4   (đổi dấu + lật)
  m₁ = 1    →  m₂ = -1     (đổi dấu + lật)

VÌ SAO? Để 2 đường giao nhau tại GÓC 90°, slopes phải:
  1. Khác dấu (1 lên, 1 xuống)
  2. Là nghịch đảo (tạo đúng 90°, không hơn không kém)
```

### 6.3 Ví Dụ — Tìm Đường Song Song & Vuông Góc

```
BÀI: Tìm phương trình đường thẳng đi qua (6, 7) và
     SONG SONG với y = (-2/3)x + 1

STEP 1: Tìm slope
  Đường cho: y = (-2/3)x + 1 → m = -2/3
  Song song → CÙNG slope → m_parallel = -2/3

STEP 2: Point-Slope
  y - 7 = (-2/3)(x - 6)
  y - 7 = (-2/3)x + 4        (distribute: -2/3 × 6 = -4)
  y = (-2/3)x + 4 + 7

  ┌─────────────────────────────────┐
  │  y = (-2/3)x + 11               │  ← PARALLEL line
  └─────────────────────────────────┘

═══ NẾU ĐỔI THÀNH PERPENDICULAR: ═══

STEP 1: Slope vuông góc
  m = -2/3 → m_perp = 3/2  (đổi dấu + lật)

STEP 2: Point-Slope
  y - 7 = (3/2)(x - 6)
  y - 7 = (3/2)x - 9         (distribute: 3/2 × 6 = 9)
  y = (3/2)x - 9 + 7

  ┌─────────────────────────────────┐
  │  y = (3/2)x - 2                 │  ← PERPENDICULAR line
  └─────────────────────────────────┘

⚠️ QUAN TRỌNG:
  • Parallel / perpendicular CHỈ thay đổi SLOPE.
  • POINT (6, 7) KHÔNG đổi — vẫn dùng point-slope bình thường.
  • Đường gốc chỉ dùng để TÌM SLOPE, không ảnh hưởng gì khác.
```

## 7. Angle of Inclination — Góc Nghiêng

### 7.1 Định Nghĩa

```
Angle of Inclination (θ) = góc mà đường thẳng tạo với TRỤC X (dương).

       y
       │    ╱  line
       │   ╱
       │  ╱
       │ ╱
       │╱ θ
  ─────┼─────── x
       │

θ luôn đo NGƯỢC CHIỀU KIM ĐỒNG HỒ từ trục x dương.
  • Horizontal line: θ = 0°
  • Line đi lên: 0° < θ < 90°
  • Vertical line: θ = 90° (undefined slope)
  • Line đi xuống: 90° < θ < 180°
```

### 7.2 Mối Quan Hệ Slope — Angle

```
Xét tam giác vuông tạo bởi line, trục x, và đường thẳng đứng:

         ╱|
   line ╱ |
       ╱  | Δy (opposite — đối diện θ)
      ╱   |
     ╱ θ  |
    ╱─────┘
      Δx (adjacent — kề θ)

Từ Trigonometry:
  tan(θ) = opposite / adjacent = Δy / Δx

Mà:
  slope = rise / run = Δy / Δx

VẬY:
  ┌─────────────────────────────────┐
  │  m = tan(θ)                      │
  └─────────────────────────────────┘

  Slope = Tangent của góc nghiêng!

Mối quan hệ:
  • Biết θ → tính m: m = tan(θ)           (thay vào calculator)
  • Biết m → tính θ: θ = tan⁻¹(m) = arctan(m) (inverse tangent)
```

### 7.3 Ví Dụ 1 — Từ Angle → Slope

```
BÀI: Tìm slope của đường thẳng có góc nghiêng θ = 30° (= π/6)

GIẢI:
  m = tan(θ)
  m = tan(30°)
  m = tan(π/6)

TỪ UNIT CIRCLE:
  sin(π/6) = 1/2
  cos(π/6) = √3/2

  tan(π/6) = sin(π/6) / cos(π/6)
            = (1/2) / (√3/2)
            = (1/2) × (2/√3)       ← lật + nhân
            = 1/√3

Rationalize (hữu tỉ hóa mẫu):
  1/√3 × (√3/√3) = √3/3

  ┌─────────────────────────────────┐
  │  m = √3/3  ≈ 0.577              │
  └─────────────────────────────────┘

KIỂM TRA: 30° là góc nhỏ → slope nhỏ (line gần nằm ngang) ✅
```

### 7.4 Ví Dụ 2 — Từ Slope → Angle

```
BÀI: Tìm góc nghiêng khi m = -1

GIẢI:
  m = tan(θ)
  -1 = tan(θ)
  θ = tan⁻¹(-1)

HỎI: "Tangent ở ĐÂU cho giá trị -1?"
  → Cần tìm góc mà sin/cos = -1
  → sin và cos CÙNG TRỊ TUYỆT ĐỐI nhưng KHÁC DẤU

TỪ UNIT CIRCLE:
  Tại θ = 3π/4 (135°):
    sin(3π/4) = √2/2
    cos(3π/4) = -√2/2
    tan(3π/4) = (√2/2) / (-√2/2) = -1 ✅

  ┌─────────────────────────────────┐
  │  θ = 3π/4 = 135°                │
  └─────────────────────────────────┘

KIỂM TRA: m = -1 (âm) → line đi XUỐNG → θ > 90° ✅
           135° → đúng là giữa 90° và 180° ✅

⚠️ NOTE: tan⁻¹(-1) cho 2 kết quả trên unit circle:
  3π/4 và 7π/4 (hoặc -π/4)
  Nhưng angle of inclination ∈ [0°, 180°) → chọn 3π/4 = 135°
```

```

## 8. Distance Formula — Công Thức Khoảng Cách

### 8.1 Phát Minh Công Thức

```
Cho 2 điểm: (x₁, y₁) và (x₂, y₂)
Tìm KHOẢNG CÁCH (distance) giữa chúng.

SỬ DỤNG PYTHAGOREAN THEOREM:

         (x₂, y₂)
            ╱|
      d   ╱  |
  (hyp) ╱   |  y₂ - y₁  (leg b)
       ╱    |
      ╱     |
(x₁, y₁)───┘
   x₂ - x₁  (leg a)

Pythagorean Theorem:
  a² + b² = c²    hoặc   leg² + leg² = hypotenuse²

Thay vào:
  (x₂ - x₁)² + (y₂ - y₁)² = d²

Lấy căn 2 vế (bỏ ±, vì distance ≥ 0):

  ┌──────────────────────────────────────────────────┐
  │  d = √[(x₂ - x₁)² + (y₂ - y₁)²]                │  ← DISTANCE FORMULA
  └──────────────────────────────────────────────────┘
```

### 8.2 Lưu Ý Quan Trọng

```
⚠️ KHÔNG ĐƯỢC RÚT GỌN CĂN RIÊNG:
  d = √[(x₂-x₁)² + (y₂-y₁)²]

  ❌ SAI: d = (x₂-x₁) + (y₂-y₁)    ← căn KHÔNG phân phối qua cộng!
  ❌ SAI: d = √(x₂-x₁)² + √(y₂-y₁)²
  ✅ ĐÚNG: Phải CỘNG cả 2 bình phương TRƯỚC, rồi mới căn.

  √(a² + b²) ≠ a + b    ← SAI LẦM CỰC PHỔ BIẾN!
  √(a² + b²) ≠ √(a²) + √(b²)

  √(a² × b²) = a × b    ← chỉ đúng cho NHÂN, không cho CỘNG!

LUÔN NHỚ: ĐẶT NGOẶC → tính trong ngoặc → bình phương → cộng → căn.
```

### 8.3 Ví Dụ

```
Tìm khoảng cách giữa (1, 3) và (4, 7):

  d = √[(4-1)² + (7-3)²]
  d = √[3² + 4²]
  d = √[9 + 16]
  d = √25
  d = 5

Tìm khoảng cách giữa (-2, 5) và (3, -1):

  d = √[(3-(-2))² + (-1-5)²]
  d = √[(3+2)² + (-6)²]
  d = √[5² + 36]
  d = √[25 + 36]
  d = √61
  d ≈ 7.81

NOTE: Kết quả có thể để dạng √61 (exact) hoặc ≈ 7.81 (approximate).
      Bài toán nào yêu cầu gì → dùng form đó.
```
