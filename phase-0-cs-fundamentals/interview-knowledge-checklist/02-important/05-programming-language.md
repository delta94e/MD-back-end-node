# 05. Programming Language — Thành Thạo 1 Ngôn Ngữ

> 📖 Tài liệu chi tiết: [Phase 1 - JavaScript Mastery](../../phase-1-javascript-mastery/)

## Chọn Ngôn Ngữ Nào?

> **Chọn ngôn ngữ bạn THÀNH THẠO NHẤT**. Phỏng vấn không phải lúc để học syntax mới. Interviewer đánh giá **algorithmic reasoning** và **thought process** — không phải ngôn ngữ.

| Ngôn ngữ       | Ưu điểm                                                | Tốt cho                               |
| -------------- | ------------------------------------------------------ | ------------------------------------- |
| **Python**     | Code ngắn, built-in mạnh (Counter, heapq, defaultdict) | Phổ biến nhất cho coding interviews   |
| **JavaScript** | Map/Set, arrow functions, gần gũi với frontend roles   | Frontend/Full-stack positions         |
| **Java**       | Strong typing, rich Collections API                    | Backend, Android, enterprise          |
| **C++**        | STL, performance, low-level control                    | Systems, HFT, competitive programming |

## Checklist Học (cho ngôn ngữ bạn chọn)

- [ ] Built-in data structures: Array, HashMap/Map, Set, Queue/Deque, Heap
- [ ] String manipulation: split, join, substring, regex basics
- [ ] Sorting: custom comparator, stable sort
- [ ] Common pitfalls: mutability, comparison (== vs ===), integer overflow
- [ ] Lambda/arrow functions, higher-order functions
- [ ] Language-specific idioms (list comprehension, destructuring, etc.)
