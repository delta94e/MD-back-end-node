## SOLID Tóm Tắt

| Principle | Tên                   | Ý nghĩa                                 |
| --------- | --------------------- | --------------------------------------- |
| **S**     | Single Responsibility | 1 class = 1 trách nhiệm                 |
| **O**     | Open/Closed           | Mở cho extension, đóng cho modification |
| **L**     | Liskov Substitution   | Subclass thay thế parent mà không break |
| **I**     | Interface Segregation | Interface nhỏ, focused                  |
| **D**     | Dependency Inversion  | Depend on abstractions, not concretions |
