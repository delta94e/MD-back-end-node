# 02. Dijkstra's Shortest Path — Weighted Graph

> 📖 Tài liệu chi tiết: [0.2.7-Advanced-Algorithms.md](../../0.2.7-Advanced-Algorithms.md)

## Checklist Học

- [ ] Dijkstra: shortest path từ 1 nguồn, weighted graph, NO negative edges
- [ ] Implementation: Priority Queue (min-heap) + distance array
- [ ] Time: O((V + E) log V) với binary heap
- [ ] Phân biệt: Dijkstra (non-negative) vs Bellman-Ford (negative edges) vs BFS (unweighted)
- [ ] Khi nào KHÔNG dùng Dijkstra: negative weights → Bellman-Ford

---

## Câu Hỏi Phỏng Vấn Mẫu

1. "Network Delay Time" — classic Dijkstra
2. "Cheapest Flights Within K Stops" — modified Dijkstra/BFS
3. "Path With Minimum Effort" — binary search + BFS hoặc Dijkstra
