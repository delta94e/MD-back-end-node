# 06. Database Replication & Partitioning

> 📖 Tài liệu chi tiết: [Phase 3 - Database](../../../phase-3-database/)

## Checklist Học

- [ ] Replication: Master-Slave (read replicas), Master-Master
- [ ] Sharding/Partitioning: range-based, hash-based, directory-based
- [ ] Consistent Hashing: minimize redistribution khi add/remove nodes
- [ ] Replication lag: eventual consistency issues
- [ ] Partitioning strategies: by user ID, by geography, by time
