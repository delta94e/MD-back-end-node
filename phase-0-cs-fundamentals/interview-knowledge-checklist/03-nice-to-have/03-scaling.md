# 03. Scaling — Vertical vs Horizontal

> 📖 Tài liệu chi tiết: [5.5-Scalability-Concepts.md](../../../phase-5-system-design/5.5-Scalability-Concepts.md)

## Checklist Học

- [ ] Vertical scaling (scale up): bigger machine, simpler, limited
- [ ] Horizontal scaling (scale out): more machines, complex, unlimited
- [ ] CAP theorem: Consistency, Availability, Partition tolerance — pick 2
- [ ] Stateless services: easier to scale horizontally
- [ ] Database scaling: read replicas, sharding strategies
